## Teil I: Kampagnen-Methodik

### 1.1 RKF-Framework (SOL-N1-Norm)

**Klassifikations-Achsen:**
- **Skala (S0–S5):** Räumliche Ausdehnung
- **Resonanzlevel (A–F):** Komplexität und Selbstreferenz
- **Parameter (Π):** Quantifizierbare Metriken
- **Ressourcen (R0–R5):** Verfügbarkeit und Zugänglichkeit

**RKF-Adresse:** `SxRy-Πz-Rw`

**Normierung:**
- **RFG⊕ = 1.0** (Erde, global, inkl. Biosphäre)
- **Ψ_bio⊕ = 1.0** (~10²⁵ bits/m³)
- **Ψ_dig⊕ = 1.0** (~10³⁰ bits/m³)
- **Φ⊕,bio = 0.2 W/m²** (globale NPP)

**Relativwerte:**
```
RFG_rel = RFG_obj / RFG⊕
Ψ_rel = Ψ_obj / Ψ⊕
Φ_rel = Φ / Φ⊕,bio
```

### 1.2 Π-Pakete

**Π-MIN (Standard):**
- T (Temperatur)
- ρ (Dichte)
- ζ (Ionisationsrate)
- RFG (Resonanz-Freiheitsgrade)
- Ψ (Informationsdichte)

**Π-BIO (E-Kandidaten):**
- Φ_heat (Geophysikalischer Wärmefluss)
- Φ_redox (Nutzbarer chemischer Energiefluss)
- η_chem (Umwandlungsanteil)
- N/P-Klasse (Chemical Habitability)
- Mix-Effizienz M (Transport)
- Ψ_growth (Szenario-Parameter)

**Π-AVI (In-Universe, optional):**
- ω (Modulationsfaktor)
- Λ (AVI-Kopplung)
- χ (Kohärenzindex)
- δR (Uhrenraten-Modulation)

### 1.3 E-Gate-Kriterien

**Quantitative Schwellen:**
```
Ψ_rel ≥ 10⁻³ (Minimum für globale Biosphäre)
RFG_rel ≥ 0.1
χ ≥ 0.70 (Bewusstseins-Emergenz)
```

**Abgeleitete Bedingung:**
```
RFG_rel × Ψ_rel ≥ 0.49
```
