## Abschluss

Erledigt durch PR #119 / OTA-TEC-0093 v1.4.

- `CANDIDATE_COMPONENT_OF` ist nun je Zielobjekt auf eine Funktions-/Variantenklasse begrenzt.
- PELICAN und Rover implizieren keinen vollständigen regenerativen Elektrolyse-/Sabatier-Kern.
- CYGNUS kann eine regenerative Transitvariante verwenden; konkrete Hardware bleibt [OFFEN].
- Gateway kann eine Stations-/Dauerbetriebsvariante verwenden; OTA-TEC-0087 bestätigt jedoch noch keine konkrete OTA-0093-Hardwareintegration.
- Frühphase-Kombifahrzeug bleibt architekturseitig separat zu prüfen.
