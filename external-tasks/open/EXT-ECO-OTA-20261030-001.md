# EXT-ECO-OTA-20261030-001 – Altbestand – OTA-TEC-Objekt-Dossier-Schema v1.5 (FROZEN) nur in Google Drive

Claude-Status: wartet auf Thomas

## Anlass

Beim Sortieren des Drive-Altbestands (Ordner „OTA (alt, bis Okt. 2026)“) wurde `OTA_TEC_OBJEKT_DOSSIER_SCHEMA_v1_5_FREEZE.md` gefunden: https://drive.google.com/file/d/12StEuDx5KbyDpWp9qz-8tf38uGDY-rYw/view

Das deutschsprachige 22-Punkte-Schema v1.5 (Metadaten-Header mit objectId/canonicalId, Zwei-Fälle-Regel für Varianten, neue Relation `FUNCTIONAL_ANALOG_TO`) liegt nicht auf GitHub. Mehrere Dossiers berufen sich aber darauf, z. B. `OTA-TEC-0034-2026-DE` („Kanonisch. OTA-TEC-Schema v1.5 (FROZEN).“), ebenso 0036, 0037, 0082, 0084, 0085. Auf GitHub liegt nur das englische, anders aufgebaute `docs/ota-tec-object-dossier-schema.md` (Stand 2026-08-29).

## Gewünschte Änderung

Thomas entscheidet über die Übernahme, z. B. als `docs/ota-tec-object-dossier-schema-v1.5.md` oder als Abschnitt im bestehenden Schema-Dokument; Beispiel-Signaturen im Text (OTA-TEC-0038/0039) auf die heute gültigen Nummern 0036/0037 korrigieren.
