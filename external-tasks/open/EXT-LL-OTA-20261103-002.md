# EXT-LL-OTA-20261103-002 — OTA-Kontextkarten klar als Fiktion oder Archivmaterial kennzeichnen

## Anlass

Living Legacy benötigt eine **umgekehrte, lesende Kontextsuche**: Nach einer freiwillig erzählten Erinnerung sollen optional passende, überprüfte öffentliche Hintergrunddokumente erscheinen. Die persönliche Erinnerung bleibt unverändert und privat. Code LL ist bis zur ECO-Bestätigung provisorisch.

## Gewünschte Änderung

OTA möge prüfen, wie ein opt-in Kontextabruf anhand neutraler KG-IDs passende veröffentlichte OTA-Werke findet. Jede Karte muss die Einordnung als fiktionale Interpretation oder dokumentarischen Quellenbezug sichtbar machen. Kein automatischer Import privater Erzählungen und keine Gleichsetzung einer fiktionalen Darstellung mit einem historischen Ereignis.

## Begründung

OTA ist Eigentümer seiner Archiv- und Fiktionsdokumente; Living Legacy verknüpft sie nur optional als Kontext.

## Betroffene Repositories

- `thomaspeterkueper/Living-Legacy`
- `thomaspeterkueper/overtime-archive.org`

## Erwartetes Ergebnis

Dokumentierter Metadaten- und Klassifikationsvertrag für optional angezeigte OTA-Karten, unabhängig von privaten Tagebuchdaten.

## Hinweise

Keine Tagebuchtexte, Rohtranskripte oder personenbezogenen Gesundheitsdaten dürfen diesen Request- oder späteren Abfragekanal passieren. Die Kontextkarte ist ausdrücklich **Hintergrund, kein Nachweis der individuellen Erinnerung**. Siehe `docs/contextual-enrichment.md` im Living-Legacy-PR #1.
