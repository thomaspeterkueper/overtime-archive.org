# OTA-CHANGE-REQ-20260928 — Iterius Legacy Reconciliation

Status: open
Created: 2026-09-28
Trigger: OTA-META-0005, 0007, 0008, 0009
Priority: high

## Reason

The Iterius Prime spatial audit found contradictions between older OTA documents and the current Generation Mars Band 1 manuscript / consolidated OTA chronology. Legacy documents may remain historical sources, but obsolete assertions must not continue to propagate as current canon.

## Rule

For each affected assertion:
- CORRECT when current canon directly contradicts it.
- DOWNGRADE when it is now provisional/open.
- QUARANTINE when spatial information remains useful but chronology is obsolete.
- KEEP when the current primary source confirms it.
- Preserve historical versions where useful, but mark superseded/deprecated explicitly.
