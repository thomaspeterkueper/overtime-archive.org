# EXT-ECO-OTA-20261126-001 – OTA-TEC-0001-2196 – Drive-Fassung v1.1 (LIM-Korrekturen) fehlt auf GitHub

## Anlass

Im Drive-Altbestand („OTA (alt, bis Okt. 2026)/TEC“) liegen drei Fassungen von OTA-TEC-0001-2196-DE (VEX-47 Explorationsdrohne). Zwei davon (`OTA-TEC-0001-2196-DE.docx`, `OTA-TEC-0001-2196-DE (1).docx`) entsprechen v1.0 und damit dem GitHub-Stand. Die dritte ist neuer:

`OTA-TEC-0001-2196-DE (2).docx` – Version 1.1:
https://drive.google.com/file/d/1SLwNgkCHV82Qjh1gBfPm-NC4zZIBRi_G/view

Laut ihrem Revisionsverlauf („Korrekturen nach LIM-Klassifikation“):

- Elaras Lied: 528 Hz → 377 Hz (außerhalb des Solfeggio-Systems, Bedeutung nicht dokumentiert)
- Elaras Status: „verstorben 2191“ statt „verschwand vor fünf Jahren“
- vollständiger Name: Elara Sinclair
- Querverweis OTA-LIM-0001-2196-DE als „Archiviert“ (statt OTA-BIO-HALBWACH-0001 „Ausstehend“)
- Revisionsverlauf mit Kuratornotiz „Das Archiv korrigiert sich selbst …“

`src/content/documents/OTA-TEC-0001-2196-DE.md` auf GitHub steht noch auf v1.0 (528 Hz, „verschwand vor fünf Jahren“). OTA-LIM-0001-2196-DE auf GitHub nennt bereits 377 Hz und Elara Sinclair – die beiden Dokumente widersprechen sich also derzeit.
